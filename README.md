# -Imagixify
A beginner-friendly image utility app to compress images, convert them to PDF, and optimize files built with passion and learning.
🪄
Imagixify is my personal project as a fresher developer.
It’s an all-in-one image utility tool that helps you compress images, convert them into PDFs, and manage your files easily — all in one place.

This project is part of my journey to learn and build real-world applications. 🚀

🌟 Features
🗜️ Image Compression – Reduce image file size without losing much quality
📄 Image to PDF Converter – Combine and export images as PDF files
⚡ Batch Processing – Handle multiple images at once
🧠 Simple UI – Clean and easy-to-use interface
💾 Lightweight – Fast and optimized for everyday use
🧰 Tech Stack
Frontend: React, JS , Material UI
Tools: image-compressor, pdf-lib, etc.
